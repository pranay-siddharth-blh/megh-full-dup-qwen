  • Add a bundle-drift check (npm run build && git diff --exit-code -- web/app) on Main and the merge queue only, not on task branches.
  • Add tests: an AST-based no-regex check for Python, a string-scan for JS, and duplicate-KI and duplicate-D checks.

  • bitbucket-pipelines.yml installs pytest inline. Its comment says "34 today".
