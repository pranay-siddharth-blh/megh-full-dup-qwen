The issueFive front-end gaps:
  • Clickable <div>s cannot be reached with the keyboard.
  • Every streamed token re-renders the whole message list.
  • ?api= would send the JWT to another origin if the CSP were relaxed.
  • Both HTML entries load Google Fonts, which an air-gapped network cannot reach.
  • Lone *_key and *_code columns still show. When the final data answer differs from its streamed draft, nothing tells the officer.
The solution

  • Honour ?api= only when import.meta.env.DEV is set. Self-host the fonts and remove the font hosts from the CSP.
  • Hide lone technical columns with a columns.js helper (keep them in the Excel export). Show a small "figures checked and corrected" note when the final text differs from the draft. Delete the dead route badge.
Don't do this
  • Masking digits in the draft; data answers are mostly digits.
